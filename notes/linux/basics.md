# 🐧 Linux Basics

---

## 📌 What is Linux?
Linux is an open-source operating system widely used in servers and cybersecurity.

---

## ⚡ Important Commands

### 📂 List files
```bash
ls
```

### 📁 Change directory
```bash
cd folder_name
```

### 📍 Show current directory
```bash
pwd
```

### 📄 Create file
```bash
touch file.txt
```

### ❌ Remove file
```bash
rm file.txt
```

---

## 🔐 File Permissions

### Example:
```bash
-rwxr-xr--
```

### Meaning:
- 👤 Owner: read, write, execute
- 👥 Group: read, execute
- 🌍 Others: read only
