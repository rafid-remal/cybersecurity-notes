# Linux Basics

---

## What is Linux?
Linux is an open-source operating system widely used in servers and cybersecurity.

---

## Important Commands

### List files
ls

### Change directory
cd folder_name

### Show current directory
pwd

### Create file
touch file.txt

### Remove file
rm file.txt

---

## File Permissions

Example:
-rwxr-xr--

Meaning:
- Owner: read, write, execute
- Group: read, execute
- Others: read only
