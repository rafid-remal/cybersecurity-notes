# Networking Basics

---

## What is an IP Address?
An IP address is a unique identifier for a device on a network.

### Example:
192.168.1.1

---

## Types of IP
- IPv4 (32-bit)
- IPv6 (128-bit)

---

## TCP vs UDP

| Feature | TCP | UDP |
|--------|-----|-----|
| Connection | Yes | No |
| Speed | Slower | Faster |
| Reliability | High | Low |

---

## What is DNS?
DNS (Domain Name System) converts domain names into IP addresses.

Example:
google.com → 142.250.x.x
