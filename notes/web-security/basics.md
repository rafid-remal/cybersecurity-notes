# Web Security Basics

---

## What is HTTP?
HTTP is a protocol used for communication between client and server.

---

## HTTP vs HTTPS

| HTTP | HTTPS |
|------|------|
| Not secure | Secure |
| No encryption | Encrypted |

---

## What are Cookies?
Cookies store user data in the browser.

---

## What are Sessions?
Sessions store user data on the server.

---

## Why Web Security Matters
- Prevent hacking
- Protect user data
- Avoid attacks like SQL Injection and XSS
